# Miniprojeto SCTEC/Senai - Pata Amiga
Esse repositório é destinado à entrega do Miniprojeto do Módulo 2, o curso de Gestão de Dados com Arquitetura Moderna do SCTEC. A ideia é criar uma estrutura que contém dados de uma empresa fictícia nomeada de Pata Amgia, um petshop que fornece dados brutos e sujos, e estes, devem ser limpos e organizados para responder perguntas de negócio.
